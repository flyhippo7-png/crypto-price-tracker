Kraken 코인 시세 감시

Kraken 공개 API 기준 시세를 조회합니다. 저장 정보는 이 PC 브라우저의 localStorage에 자동 저장됩니다.
상태: 초기화 중
마지막 조회: -
등록 코인: 0개
입력 예시: BTC, ETH, SOL, XRP 또는 Kraken 거래쌍인 XBT/USD, ETH/USD. Kraken에서는 비트코인을 API 내부에서 XBT로 표기하는 경우가 있습니다.
자동갱신: 10초 최대 등록: 200개 🚨경보기준:
주의: 이 페이지는 시세 조회용 예제이며 매매 기능은 없습니다. Kraken API 응답 지연, 네트워크 차단, 거래쌍 미지원에 따라 일부 종목은 조회되지 않을 수 있습니다.
